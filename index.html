CASE STUDY
Rancang Bangun Alat Pengering dan Penggiling Cabai Rawit Berbasis PLC Outseal Nano
✕
‹
›
Deskripsi Teknis

Tugas akhir ini berfokus pada perancangan alat pengering dan penggiling cabai rawit otomatis berbasis PLC Outseal Nano dengan tiga tahap proses terintegrasi: pengeringan, pemindahan, dan penggilingan, dengan kapasitas rancangan hingga 5 kg per proses.

Proyek ini mencakup perancangan mekanik 3D, perakitan panel kontrol, pemrograman PLC, serta integrasi sensor dan aktuator. Analisis tegangan menggunakan Finite Element Analysis (FEA) pada Autodesk Inventor menunjukkan tegangan Von Mises maksimum sebesar 19,44 MPa, di bawah yield strength material sebesar 250 MPa, sehingga struktur dinyatakan aman.

IoT-Based Greenhouse Monitoring System
✕
‹
›
Deskripsi Teknis

Proyek ini mengembangkan sistem monitoring greenhouse tanaman melon berbasis IoT untuk memantau suhu, kelembapan udara, intensitas cahaya, dan kelembapan tanah secara real-time.

Sistem menggunakan ESP32, Firebase Realtime Database, dan aplikasi smartphone untuk menampilkan data pemantauan secara praktis. Sensor yang digunakan meliputi SHT31-D untuk suhu & kelembapan, BH1750FVI untuk intensitas cahaya, dan soil moisture untuk kelembapan tanah, diintegrasikan melalui MIT App Inventor.
